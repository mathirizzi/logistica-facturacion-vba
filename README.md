# logistica-facturacion-vba
Script para automatizar facturacion de servicio logistico a traves de excel.
## Objetivo

Calcular automáticamente:

- Estadías de pallets
- Movimientos IN
- Movimientos OUT
- Picking (PK)
- Detección de incidencias

## Tecnología

- VBA / Excel
- Git
